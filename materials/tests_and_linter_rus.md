# Тесты и линтер

Сегодня у тебя два помощника, которые проверяют код. Они смотрят на разное, и нужны оба.

- [Тесты](#тесты)
- [Линтер](#линтер)
- [Чем они отличаются](#чем-они-отличаются)

## Тесты

Тест — это программа, которая вызывает твои функции и сравнивает то, что они вернули, с тем, что должно получиться. Тест отвечает на вопрос «**правильно ли считает** код».

Запуск из корня репозитория:

```
python3 testing/test_bank.py       — все задания
python3 testing/test_bank.py 2     — только Задание 2
```

Для каждого задания тест пишет одну строку:

| Ответ | Что означает |
| --- | --- |
| `Задание 2: пройдено` | Функции этого задания работают как надо |
| `Задание 2: не начато` | Функции ещё возвращают пустые значения из заготовки |
| `Задание 2: не пройдено — …` | Функция работает не так; после тире — первая найденная причина |
| `…: не пройдено — функция упала: ValueError: …` | Функция остановилась с ошибкой; её разбор — в `traceback_40_rus.md` |

Как читать причину. Например:

```
Задание 2: не пройдено — find_question(вопросы, 99) должна вернуть None: такого вопроса нет
```

Тест вызвал `find_question` с номером `99`, которого в банке нет, и ждал `None`, а получил что-то другое. Найди в своей функции место, где она возвращает результат, и подумай, что будет, если нужного вопроса не нашлось.

Тесты проверяют функции не только на выданном банке, но и на маленьких банках, которые создают сами. Поэтому число вопросов нельзя вписать в код: на другом файле ответ будет другим.

Код тестов можно читать, но не менять.

## Линтер

Линтер читает код, **не запуская** его, и показывает места, написанные небрежно. Он отвечает на вопрос «**аккуратно ли написан** код», но не знает, правильно ли он считает.

Запуск из корня репозитория:

```
python3 src/partner/lint.py src
```

Если замечаний нет, линтер так и пишет: `Замечаний нет.` Иначе — список замечаний:

```
src/bank.py:12: L020 модуль не должен печатать: печатает точка входа
```

Файл, номер строки, код замечания, объяснение. Иди в эту строку и исправляй.

| Код | Замечание | Что означает |
| --- | --- | --- |
| `L000` | Файл не разбирается | В коде синтаксическая ошибка: программа не запустится вообще |
| `L001` | Строка длиннее 100 символов | Такую строку не прочитать без прокрутки; раздели её |
| `L002` | Табуляция в строке | Отступы делаются четырьмя пробелами |
| `L010` | Импорт не используется | Подключён модуль, который нигде не нужен |
| `L011` | Переменная заведена и не используется | Значение посчитано и забыто — часто это след ошибки |
| `L020` | Модуль не должен печатать | В `bank.py` есть `print`. Печатает только `main.py` |
| `L021` | Нет импорта модуля | `main.py` не подключает `bank.py` |

## Чем они отличаются

| | Тест | Линтер |
| --- | --- | --- |
| Запускает код | Да | Нет |
| Проверяет | Правильность результата | Аккуратность записи |
| Может пройти, а другой нет | Код считает верно, но в `bank.py` остался отладочный `print` | Код аккуратный, но считает неверно |

Задание засчитано, когда и тест, и линтер довольны.
