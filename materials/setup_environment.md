# Подготовка рабочего места

Выполни техническую подготовку под своей учебной учётной записью до начала заданий. Скрипт создаёт личное окружение Python и устанавливает общий набор библиотек: matplotlib, FastMCP, Pydantic, pytest и их зависимости.\
Полный список с версиями — в `requirements-campus.lock.txt`.

Для запуска на macOS и Linux нужны установленные ИТ Python 3.12+ с venv/pip и Bash. На Windows используй терминал уже подготовленной ИТ WSL2, а не PowerShell. Если этих программ нет, обратись к стаффу. Комплект не устанавливает системное ПО и не требует прав администратора.

## Подготовь окружение

1. Распакуй `student-preflight-12.10.zip` в свою доступную для записи папку. Не запускай файлы внутри архива.
2. Открой терминал в распакованной папке `student-preflight-12.10`, где лежит `run.sh`.
3. Выполни:

```bash
bash run.sh
```

Дождись завершения. Скрипт установит пакеты в `$HOME/.venvs/bassein-12-10` и сохранит `preflight.json` рядом с `run.sh`. Во время подготовки активировать окружение вручную не нужно. В ZIP нет самих библиотек: для установки нужен доступный в кампусе источник пакетов либо отдельная локальная папка пакетов от ИТ.

## Проверь результат

- `PASS` — проверка прошла.
- `project-d8: SKIP` — ожидаемый результат: проект Д8 в этот комплект не входит. Его техническую проверку ИТ проводит отдельно.
- `reference-python: WARN` — Python отличается от версии 3.12.14 из материалов. Передай предупреждение стаффу для проверки ИТ.
- Любой `FAIL` или ошибка запуска — передай стаффу вывод терминала и `preflight.json`, если он создан. Не пытайся устанавливать пакеты в системный Python.

Отчёт относится только к текущему компьютеру и учётной записи. Он не заменяет приёмку кампуса ИТ.

## Работай в окружении

В каждом новом терминале перед командами Python выполняй:

```bash
source "$HOME/.venvs/bassein-12-10/bin/activate"
python3 -c 'import sys; print(sys.executable)'
```

Выведенный путь должен вести внутрь `$HOME/.venvs/bassein-12-10/bin/`. Затем перейди в папку проекта и выполняй его команды в этом же терминале. Окружение не добавляй в Git.

Подготовка выполняется один раз для твоей учётной записи на рабочем месте. Повторный запуск `run.sh` снова запускает установку по списку версий. Во время выполнения заданий голодных дней и экзаменов повторную подготовку не запускай: используй уже подготовленное окружение и команду активации. Если переходишь на другой компьютер, уточни у стаффа, доступно ли там твоё окружение. Установленные библиотеки не меняют правила заданий: если разрешена только стандартная библиотека Python, используй только её.

## Если ИТ выдало локальные пакеты

При отсутствии доступа к сетевому источнику ИТ может выдать папку `wheelhouse` с пакетами для твоей ОС, архитектуры и версии Python. Тогда вместо обычного запуска выполни:

```bash
bash run.sh --wheelhouse "/путь/к/wheelhouse"
```

Замени путь в кавычках на фактический путь, предоставленный ИТ. В этом режиме установка не обращается к сетевому индексу пакетов. Локальные пакеты в данный ZIP не включены; без источника пакетов новая установка не выполнится. Проверку на каждом используемом образе macOS, Linux и WSL2 проводит ИТ.
